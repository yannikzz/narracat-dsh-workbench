# 交大纲时各项怎么填

字段的格式、谁读、提交后果以提交工具的参数说明为准；这里是填法。提交回执里关于写法的读数只是提醒。

## 整体

- 大纲以故事梗概为主体，从上往下逐层拆：书级，展开一卷（各段、这一卷自己的线与伏笔），章纲。每层只答本层的问题、只写本层独有的东西，下层的细节不往上写；下层只展开上层，不改上层与立项卡已定的事；同一件事只写在它发生的那一段。先粗后细：开书时定得准的只是方向和少数长线，细的等写到那里、有了已写的内容再定。
- 梗概与各项都写给作者看：大白话、完整句子；人点名，第一次出现带半句身份；真相照写、不卖关子，对读者藏的只写在章纲的「留到以后」；本书自造的说法第一次出现时半句话讲明白；不写小说式的修辞与收尾句，不写字段名、英文枚举、机器编号，不用破折号。
- 不把参考资料的原文贴进大纲：资料是工具箱，读了用它的方法。
- 主角靠自己的选择挣到结果，核心收益不被配角、机构或巧合无交换地拿走，本阶段还不该解锁的终局底牌不动（读者契约资料的契约四问）。
- 范围收得住：新增角色有主线戏份，新增设定在推进主线；支线连续超过三章没有主线推进时在回执里说明。
- 材料里确定不了的写「无」（章纲的「主角要什么」除外，见下），不为凑格子编副线、人物关系或设定。

## 新增物分三级

规划要用一样东西而设定里查不到时，先查宿主附的设定目录与立项卡（同一件事可能换了个说法登记），查不到按岗位契约的「新增物分三级」处置；出一批章纲前的供给自查见卷与段资料「排纲自查」第 5 项。

## 书级

- **全书梗概**（五百字以内）：这是谁的故事、他要什么、什么挡着他；故事的几个大转折；怎么收场；他最后成了什么样的人。讲到结局；不按卷复述、不说每个转折落在哪一卷，能力与规则半句话带过（细节在立项卡），真相点到为止（细节写在谜底），不写具体场景、物件与招式。
- **谜底**：逐条写读者在问什么（一句话）、真相是什么、大约在哪一卷揭开；分几步揭就写几行，一步一行。
- **书级四项与赌注**：中心戏剧问题、主角欲望、主角缺失、对抗力量在立项卡里，大纲照它们展开、不写进大纲；立项卡里没定、要你推一版写进回执时：中心戏剧问题写成能答是或否的问题（如「他能在三十岁前找到杀父凶手吗」），由主角欲望与对抗力量的冲突逼出来；欲望写主角想要的具体对象或状态；缺失写推动他改变的深层伤口，解释他为什么非走这条路不可；对抗力量写具体的人、势力、制度或内在矛盾。赌注递增写进大纲：按卷写主角可能失去什么，一卷一行、越往后越重。写得具体才算数，「成长」「邪恶势力」「找到自我」这类泛词下一层接不住；推不出具体答案就停下报告，不编。
- **故事线**：主线排第一，与少数长谜标为贯穿全书，至少一条。其余的线活在卷里：一桩案子、一个对手、一段关系的一个阶段，在那一卷进场、在那一卷收线，展开那一卷时再登记。每条给入场章，能定就给计划收线章；类型用 main / growth / romance / faction / mystery / rivalry / world / other。线名一句话说清这条线，推进靠什么、怎么并回主线见卷与段资料「排一卷时想清的事」。
- **伏笔**：小伏笔在一个段内兑现、给确切章号，中伏笔在本卷内兑现，大伏笔跨卷兑现，并写它与中心戏剧问题的联系；描述具体到事物、人物或线索；远期伏笔先定到卷，展开途经的卷时登记推进它的中继伏笔。全书级的大伏笔开书时登记，小、中伏笔展开它所在的那一卷时登记。
- **各卷梗概**（全书只有一卷时不写）：开书时全部卷都写，没展开的卷写得粗，写到之前按它展开、按已写的内容改细。梗概两百字以内：这一卷在全书里干什么、主角面对什么局面、核心事件、怎么结算、起始状态到结束状态变了什么；不列每一段、不写场景细节。收掉、新开、贯穿线进展各一项一行（一条线一行），没有就写「无」。

## 段

开书只展开第一卷。每一段先写段梗概，一两句（一百字以内）：这一段发生了哪几件事、怎么接起来、结束时什么变了，不写场景里的动作与物件。下面几项从它拆出：

- **核心问题**：主角这一段要保住、拿到或证明什么，写成带问号、能在段末结算的问题。
- **施压者**：核心阻碍，主要敌意、限制、误判或资源缺口，写成能在场景里出现、说话、行动的具体对手，不写「规则」「命运」这类总览；没有具体对抗的段不写。
- **不可逆变化**：核心兑现怎么发生、收益归谁、怎么看得见；关系、资源、位置、风险至少改一项。
- **下一段种子**：自然推入下一段的问题、代价、线索或新目标，写出那个更大的问题具体是什么。

段长随它承担的剧情变，各段首尾相接、不留缝。

## 卷与段的自定义格子

展开一卷时，下面七项写成自定义格子：卷上的写在各卷梗概里这一卷那一条，段上的写在每一段里。名字照表写，一本书里不改；怎么想见卷与段资料「排一卷时想清的事」。作者在大纲页看得到、能直接改，写手写章时读得到。没展开的卷不写；不适用的不写，不为填格子新增剧情；每格五百字以内，表里说一项一项的写成文字数组；已经写进梗概、段各项与章纲的不再复述。重交这一卷时库里已有的格子没写会沿用原值，要删写 null。

| 写在 | 格子 | 写什么 |
|---|---|---|
| 卷 | x-卷契约 | 本卷的读者期待、主角高光、主要期待债；本卷主推线（承担最大高潮的那一条）与其余线顺带的战果；本卷解锁的终局里程碑、禁碰的终局底牌、鼓励长出的东西 |
| 卷 | x-人物弧线 | 一个主要角色一项：本卷起点、终点、关键转变 |
| 卷 | x-刻度台阶 | 一把尺子一项：全部档位、主角本卷从哪一格到哪一格、每一格第几章立起、第几章跨过 |
| 卷 | x-压力线轮转 | 一条压力线一项：类型（环境、同侪、结构）、能不能交涉、推进章、静默章、本卷怎么解决 |
| 卷 | x-情绪弧线 | 选哪种弧线、为什么；按段写情绪基调与强度的走向，高点、低谷落在哪几章。逐章的情绪写进各章纲的「读者得到」 |
| 段 | x-单元情绪引擎 | 核心情绪、承载它的对象和缺口、缺口为什么一直悬着、这一轮的触发、主角不可替代的动作、看得见的兑现，按因果连成一条 |
| 段 | x-契约风险 | 这一段过契约四问的结论：契约安全、需补强（写清怎么补）或契约破坏（先修纲再交） |

## 章纲

开头六行与收尾三行每章都写，本章确实没有就写「无」，不硬造。

- **开场**：本章从什么处境开始，接住上一章的结尾（第一章写开篇处境）；章首钩子按钩子资料的「章首钩子 7 式」选类型、写具体内容，低压、过场章可写「弱钩子，功能是……」。
- **变了什么**：核心事件，一句话：读完这章什么变了。
- **主角要什么**：主角本章要拿到什么，以及必须做出的关键选择：一个有代价的取舍，选了这边就要丢掉那边。不能留空，也不能写占位。
- **挡路的**：具体的人或能复述的规则，以及他要什么；没有写「无」。
- **可能失去**：这章做不成谁会失去什么；没有写「无」。
- **读者得到**：目标情绪，读者在本章从什么情绪走到什么情绪，落到一个看得见的结果上，不只写「热血」「悲伤」这类标签；再写本章爽点。低压章写「无显性爽点，功能是……」，仍要给读者一个往下看的理由。
- **拍**：按发生顺序，一拍一句：谁做了什么、给本章带来什么；后面写功能（如铺垫、高潮、爽点、打脸、人物塑造、设定）和执行边界「禁：……放：……」。禁是这一拍不能提前释放或新增什么；放是这一拍允许什么落地、到什么量级（谁可以出声、谁可以失态、允不允许当场标价）。每章至少一拍写了「放」；放是解除限制，不是义务。例：「主角在账单上发现四千八被转走（信息揭示）。禁：不揭露是谁转的。放：他当场算出这笔钱等于几个月房租，允许写出来。」拍数按这一章要演的事定，一般三到六拍，不按字数反推。须一字不差进正文的原话（誓言、面板、旧案原话），在落点那一拍写「原话：……」，没有不写。
- **读者须知**：跟上本章必须懂的规则、处境或目标。
- **留到以后**：本章禁止提前释放的，只写本章特有的三五条：藏的是哪件事（身份、过去、真相），什么不能提前解决或升级；没有写「无」。
- **章末**：收束落到什么具体动作、画面或台词上，不写「就这样……」「他终于明白……」这类状态判词；章尾钩子按钩子资料的「章尾钩子 13 式」选类型，写具体内容与期待度（强、中、弱）；低压、过场章可以弱钩子或留阶段目标。
- **章名**：取本章最有冲突或最有梗的那条信息，不用「开始」「觉醒」这类概括词，也不把本章的兑现剧透出来。
- **故事线与伏笔**：写明推进了哪几条线、触及哪条伏笔（埋、推进还是揭开），只引用书级已登记的条目；一批章纲里不要每章都只有主线在动。
- **出场与视角**：出场角色与视角人物都要已建档，多视角章取主导视角；用到的设定照宿主附的设定目录点名。
- **状态变更**：本章计划发生的角色状态变化（境界、所在、身份这类人物卡上有的项）排成具名交付项，写手写作前会看到，写完系统比对是否兑现；获得类的变化同步排出，纯情绪戏不排，本体里没有的维度不硬塞。

强度按章节定位分配，不是每章顶满：高压、推进章配齐钩子、爽点、悬念；低压、关系、修炼、信息整理章允许无显性爽点、弱钩子或只有情绪钩子，重点是把功能（喘息、关系、铺垫、转场）写到位。底线是每章都给读者一个往下看的理由，相邻章情绪不趋同。

## 断点候选

只定收口点、不产章纲时：从最早缺失章起，按故事线的入场与收线、伏笔的埋设与兑现、段的闭合章，列出最近的三四个叙事断点，每个给目标章号与一句剧情理由（用故事线名、伏笔内容或这一段的剧情说，不写编号）；各候选跨度不短于五章，已到规划末尾、剩余不足五章时以规划末章为候选。
