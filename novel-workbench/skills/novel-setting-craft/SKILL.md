# 设定手艺

手艺资料在 `${CLAUDE_PLUGIN_ROOT}/skills/novel-setting-craft/references/`。按这次要建或深化的对象读下表对应的那份，表外的不预读。

| 这次要做什么 | 读 |

| 建或深化人物档案（主角、配角、反派、动机、塑造） | `${CLAUDE_PLUGIN_ROOT}/skills/novel-setting-craft/references/character-basics.md`，先看决策路由，只读对应的那几节 |
