# 人物速写与说话方式

> 写人物速写（每个建档的人都有一段，写手每章只先拿到它）和档案里的「说话示范」时读。差异化的几处来由取自 oh-story-claudecode 对话资料「人物语言差异化」一节；按本方案的写法改了两处：说话方式写成示范台词、不按维度写形容（形容会被写手照字面执行到底，人人都短都冷），口头禅可以没有。

## 速写写什么

150–300 字，写这个人在场时读者该感到的样子——在人前怎么待人、最在乎什么、碰到哪种事会失态。写稳定的特质，不写会随剧情变的处境（那些由记忆跟着正文记）；与档案一致、不另编，档案还没写到的就不写。

说话那部分不用「话少」「说话短」「长篇大论」这类形容，写两三句他真会说的话来示范：一句平常场合的，一句对某个特定的人说的，一句急了、慌了或得意时的，每句照他当时的口气带上标点（问就用问号，急就用感叹号，吞吞吐吐就用省略号）。口气从他的出身、身份和在乎的东西里来；示范句只是让写手摸到这个人怎么说话，正文不照搬；口头禅可以没有，有也只给一个。

## 示范台词从哪想

想不出这个人会说什么，说明人设还模糊：先从下面几处找来由，再落成那两三句。

| 从哪想 | 落到台词里 |
|------------|------|
| 惯用语 | 有身份或经历来由才给，不给每人硬配口头禅；口头禅可以没有，有也只给一个 |
| 信息偏好 | 技术型带专业术语，江湖人带切口 |
| 立场固定 | 某角色永远从某个角度发言（悲观派/乐观派/务实派） |
| 身份影响措辞 | 老者/少年/贵族/市井，身份不同则措辞、自称、敬谦词不同 |
| 性格影响语气 | 智谋型话里有话；鲁莽型想到什么说什么；冷静型措辞精确，偶尔情感外露反而有冲击 |
| 关系影响态度 | 初见/熟悉/对立/亲密，关系阶段不同则语气与信息量不同；「对某个特定的人说的那一句」从这里挑 |

不要求遮住名字也认得出谁在说话：争、求、瞒、慌这些要紧处口气像他自己就够，日常来回分不出是谁很正常。
