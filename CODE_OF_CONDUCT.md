# Code of Conduct

Narracat · 叙述猫 is a small project. We want the issue tracker, discussions and pull requests to stay useful and respectful.

## Expected behavior

- Be direct and kind; critique the code or the idea, not the person.
- Assume good intent, but be clear about bugs and impact.
- Respect privacy: never paste a real manuscript, API key, token, or personal path into an issue.
- Keep discussions on topic; move long design debates to Discussions.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized content, doxxing, deliberate intimidation, or repeatedly dismissing someone's reports without evidence.

## Reporting

Use GitHub's private contact to reach the maintainer at https://github.com/yannikzz/narracat-dsh-workbench/security/advisories/new for a confidential report, or open a normal issue if the matter is not sensitive. Reports will be reviewed and handled discreetly.

## Enforcement

The maintainer may edit or remove comments, close threads, or block accounts for behavior that makes the project unsafe or unproductive. This applies to project spaces (issues, discussions, pull requests) and to public interactions made on behalf of the project.

This is intentionally a short policy, not a legal document. Be a good collaborator.
